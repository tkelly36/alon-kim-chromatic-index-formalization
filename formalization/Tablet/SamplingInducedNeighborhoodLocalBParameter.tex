\begin{definition}
For a graph $G$, a vertex $r$, a finite set $X$, and a scale $\Delta$, define
the induced-neighborhood bookkeeping expression by
\[
\frac{|X|}{\Delta}
-\frac{|\mathcal J_2(X)|}{\Delta^2}
+\frac{|\mathcal J_3(X)|}{\Delta^3},
\]
where $\mathcal J_2(X)$ and $\mathcal J_3(X)$ are the independent two- and
three-element subsets of $X$.  The vertex $r$ is a parameter carried for the
downstream induced-neighborhood application; it does not otherwise affect the
value of this expression.
\end{definition}
