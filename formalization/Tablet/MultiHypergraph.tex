\begin{definition}
A \emph{multihypergraph} consists of a vertex type $V$, an edge-index type
$E$, and an assignment sending each edge index $e\in E$ to a finite set
$e\subseteq V$ of vertices.  Distinct edge indices may be assigned the same
vertex set, so this represents the paper's convention that the edge collection
is a multiset.
\end{definition}
