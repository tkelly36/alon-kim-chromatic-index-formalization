\begin{definition}
For $q\in\mathbb N$, let $A_q$ be the multihypergraph with vertex set
$(\mathbb Z/3\mathbb Z)^2$ and edge-index set
$\{\ast\}\sqcup((\mathbb Z/3\mathbb Z)^2\times\{0,\ldots,q-1\})$.
The index $\ast$ (represented by \texttt{none}) carries the vertical line
$\{(0,y):y\in\mathbb Z/3\mathbb Z\}$; the index $(m,a,i)$
(represented by \texttt{some}$(m,a,i)$) carries
$\{(x,mx+a):x\in\mathbb Z/3\mathbb Z\}$.
Thus there are $q$ separately indexed copies of every nonvertical line.
\end{definition}
