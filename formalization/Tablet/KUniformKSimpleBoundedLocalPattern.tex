\begin{definition}
For natural numbers $k$ and $D$, a bounded local pattern for the
$H(k,k,D)$ extremal reduction consists of an assignment of a finite vertex
set to each edge label, where the vertex-label type is the finite set
\[
\{0,\ldots,k+k^2(D-1)-1\}
\]
and whose edge-label type is the finite set
\[
\{0,\ldots,1+k(D-1)-1\},
\]
together with a distinguished edge label $p$, such that the multi-hypergraph
defined by this edge assignment belongs to $H(k,k,D)$.
\end{definition}
