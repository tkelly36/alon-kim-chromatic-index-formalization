\begin{helper}
Let \(V\) be finite and let \(\nu\) be a measure on activation--priority
pairs \((A,\pi)\in\mathcal P(V)\times\mathbb R^V\).  Fix
\(0\le p\le1\).  Assume that every activation atom satisfies
\[
\nu\{A=A_0\}=
\operatorname{ofReal}\!\left(p^{|A_0|}(1-p)^{|V|-|A_0|}\right)
\]
for every \(A_0\subseteq V\).  Assume also that activated priorities are
supported in the unit cube on each atom, in the sense that
\[
\nu\{A=A_0,\ \pi(q)\in[0,1]\text{ for every }q\in A_0\}
=\nu\{A=A_0\}
\]
for every \(A_0\subseteq V\).  Finally, assume the full lower-rectangle
product law: for every \(A_0\subseteq V\) and every threshold vector
\(t:V\to\mathbb R\) with \(t(q)\in[0,1]\) for all \(q\),
\[
\nu\{A=A_0,\ 0\le \pi(q)\le t(q)\text{ for every }q\in V\}
=\nu\{A=A_0\}\operatorname{ofReal}\!\left(\prod_{q\in V}t(q)\right).
\]
If \(u\ne v\), then
\[
\nu\{u,v\in A,\ \pi(q)\in[0,1]\text{ for every }q\in A,\ \pi(u)=\pi(v)\}=0 .
\]
\end{helper}
\begin{proof}
The set \(D=\{q\in\mathbb R^V:q(u)=q(v)\}\) is the kernel of the
linear functional \(q\mapsto q(u)-q(v)\).
Since \(u\ne v\), this functional takes value \(1\) on the vector equal
to \(1\) at \(u\) and \(0\) elsewhere, so its kernel is a proper linear
subspace. Proper linear subspaces have Lebesgue volume zero.
The kernel is closed, hence Borel measurable.
Each activation atom has finite mass by its displayed
\(\operatorname{ofReal}\) formula. Applying
\noderef{SamplingPriorityProjectionVolumeNull} to \(D\) and the full
lower-rectangle law gives \(\nu\{(A,q):q\in D\}=0\).
The event in the statement is contained in this inverse image, so
monotonicity gives the required zero measure.
\end{proof}
