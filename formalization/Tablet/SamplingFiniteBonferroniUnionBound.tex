\begin{lemma}
For any nonnegative weights $\mu$ on finite subsets of a vertex set and any
finite set $X$,
\[
\Pr[I\cap X\ne\emptyset]
\le
\mathbb E|I\cap X|
-\mathbb E\binom{|I\cap X|}{2}
+\mathbb E\binom{|I\cap X|}{3}.
\]
\end{lemma}
\begin{proof}
For a realized set $S$, put $n=|S\cap X|$.  The elementary pointwise
inequality
\[
\mathbf 1_{n>0}\le n-\binom n2+\binom n3
\]
holds for every $n$: it is immediate at $n=0$, while for $n>0$ the right
side equals $1+\binom{n-1}{3}$.  Multiplying this pointwise inequality by the
nonnegative mass $\mu(S)$ and summing over all finite subsets $S$ gives the
displayed Bonferroni inequality.
\end{proof}
